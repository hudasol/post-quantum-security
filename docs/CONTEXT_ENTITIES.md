# Context: public facts about three Abu Dhabi organisations

Author: Huda Mueen. Generated by `scripts/build_context_entities.py` from `data/context_entities.csv`; do not edit by hand.

Every fact below comes only from public web pages or official press releases of the organisations concerned, or from the Abu Dhabi Media Office, and is paraphrased in plain words. This repository is a student research seed. It has no relationship with, and no endorsement by, any of these organisations, and nothing here should be read as implying one. All pages were retrieved on 2026-10-20; pages change, so each fact holds only as of that date.

Facts recorded: 20 in total (TII and ATRC: 8, EDGE Group: 6, ADEO: 6).

Reading notes:

- ADEO publishes little on technology under its own name. The ADEO section therefore also lists Abu Dhabi government statements on cyber security and digital strategy; each such row says when ADEO is not named.
- Where a page does not name algorithms, licences or embedded targets, the row says so rather than filling the gap.
- Dates of programmes and calls are those stated on the page; some windows have already closed.
