Author: Huda Mueen. Generated by `scripts/meta_analysis.py` from `data/evidence.csv`; do not edit by hand. Label: published. Seed for the bootstrap: 20261020.

Scope: 415 microcontroller rows with a cycle count and a plain operation (keygen, encaps, decaps, sign, verify), in 245 groups of scheme family, parameter set, operation and core class; 27 groups have rows from two or more sources. They differ in library, optimisation, compiler, clock, flash wait states, cache state, counter and statistic (minimum, mean or median); the clock and the row ids of every group are listed in `data/meta/cycle_groups.csv` so that comparability can be judged row by row.

## What the spread says

Inside groups with two or more sources, the largest published value is 1.46 times the smallest at the median group (range 1.07 to 4.67 over 27 groups). The spread mixes implementation choices (portable C against assembly, stack against speed optimisation) with measurement conditions; a single published number for an operation on a core class therefore carries an uncertainty of that order before any board is measured.
