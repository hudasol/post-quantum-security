## Why this file exists

On 2026-10-29 the author fields of early commits and some commit message trailers were corrected. Changing the metadata of a commit gives it a new ID, and every later commit then gets a new ID as well. No file, tree, parent order or date changed: for each of the 593 commits the tree ID before and after is the same (`data/history/commit_ids_2026-10-29.csv` lists the earlier ID, the current ID and the tree ID of each). Commit IDs quoted in documents written before that date refer to the earlier IDs; the map translates them. The history was not rewritten again afterwards.

A prediction file is verified by its SHA-256, not by a commit ID: compute the SHA-256 of the file and compare it with the hash file committed with it. The table below does this for every hashed prediction file and names the commit, by its current ID, that first added each one.
