## Scope and reading rule

Round 6 collected published designs and measurements of post quantum and classical authentication and key exchange for drones, UAVs, MAVLink, ROS 2 and DDS, robots and other constrained wireless links, and of post quantum secure boot and update on embedded processors. Searches used the web search and fetch tools of the working environment; refused fetches are recorded in the CSV and in `data/raw/S14_dblp_log.csv`, not worked around.

Works retrieved: 22. Full text read directly from an author supplied copy: 2 (RW01, RW02). Full text read only through the summarising fetch tool: 13. Abstract only, partly read or not retrieved: 7 (RW04, RW06, RW15, RW18, RW19, RW21, RW22).

Values are copied as each source states them, with the table or section in brackets. Under the round 5 rules (inclusion 4 and deviation 3) a value read only through the summarising fetch tool or only from an abstract is not usable as evidence until it is read directly; the rows usable as evidence are RW01, RW02. None of these values enters `data/evidence.csv` in this round.

## What is new here, and what is not

Among the 22 works retrieved, 8 address drones, UAVs, unmanned systems or MAVLink directly (RW01, RW11, RW12, RW13, RW14, RW15, RW17, RW21). A post quantum handshake measured on embedded hardware is reported by RW03; over an emulated link from a host by RW01, RW05; and as an estimate composed from per operation costs by RW11, RW14. A machine checked symbolic model of the design is reported by RW07, RW11. Availability of a message stream under loss is reported by RW10, for vehicle to vehicle broadcast rather than a command channel.

Against this retrieved set, what this study can add is the combination, not any single part, provided the round 6 work completes as planned (`docs/LIMITATIONS_AND_PLAN_R6.md`): one code base that executes the command channel baselines, from no authentication to a post quantum signature per command, on the Ibex and CV32E40P cores at cycle level; the same designs checked in ProVerif, including a replay cache rule; and command availability modelled under the published, strict next sequence and replay cache rules on telemetry class links. Each part has precedents above: embedded handshake measurements, emulated UAV link handshakes and Tamarin models of a UAV key exchange. Until the round 6 results are integrated, this paragraph states a plan, not a finding.

Limits of this comparison. The values above were measured by others on other processors, libraries, links and settings, so the table compares designs and methods, not numbers. Cycle accurate simulation of open cores is not a measurement on a Cortex-M board or over a radio, which this study still lacks. The retrieved set is not exhaustive: the dblp index could only be reached through search engine results (`docs/SEARCH_PROTOCOL.md`, round 6 section), several full texts were refused, and works not found by the searches may exist.
