# Host measured baseline, third round

Author: Huda Mueen. Generated by `bench/host/native_v3/analyze_native_v3.py` (called by `run_native_v3.sh`). Label: **host measured**. Nanoseconds on a PC; not microcontroller results and not transferable to one. Used only for ratios between algorithms and for rank order.

## Method

CPU: AMD Ryzen 7 7730U with Radeon Graphics; Linux virtual machine (WSL2) on a laptop; CPU frequency governor not controllable without administrator rights; gcc (Ubuntu 15.2.0-16ubuntu1) 15.2.0; flags -std=c99 -O2 -DBENCH_HOST (bench/mcu/Makefile host target). 15 runs per binary, interleaved in an order shuffled with seed 20261018, each pinned to CPU 2, 420 iterations per operation; the first 20 iterations of every run are dropped; one discarded warm up pass first. Statistic: median per run, then median and median absolute deviation (MAD) of the run medians. Machine state before each run is in `state.csv`: load average 0.70 to 1.01; reported CPU MHz 1996 to 1996 (the value the virtual machine reports; it need not follow the real clock).

## Limits

1. The host runs mlkem-native and mldsa-native; the published rows are PQClean reference code on a Cortex-M4. Rank agreement does not mean cost agreement.
2. CPU frequency was not under control; interleaving spreads its effect over all algorithms but does not remove it.
3. ML-DSA signing time depends on the message; pqm4 reports a mean, this table a median.
