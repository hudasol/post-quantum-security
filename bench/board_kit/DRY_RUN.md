## Purpose

This run proves that the board session pipeline works end to end before a board is borrowed: build (pqm4 images and the harness through pqm4's platform layer), run, capture, parse, compare. It proves nothing about cycle counts. QEMU does not model the core clock, flash wait states or caches; its SysTick and DWT values are not cycle counts. They are labelled emulated and compare.py excludes them from every cycle comparison.
